# 📑 HackMatrix: Pages List

**AI-Powered Web Threat Detection & Digital Trust Intelligence**

---

### 1. 🌐 Landing Page (`/`)
Public homepage introducing the platform, featuring an instant URL quick-scanner, core technology highlights, and live threat metrics.

### 2. 🔐 Authentication (`/login`, `/register`)
Secure sign-in and account registration portal providing role-based access for security analysts, developers, and guests.

### 3. 🛡️ Real-Time Threat Scanner (`/scan`)
Primary command dashboard to scan a single URL and view its classification (Phishing vs Legitimate), confidence score, risk level, and 16 extracted features.

### 4. 🔬 SHAP Explainability Studio (`/explain`)
Explainable AI interface visualizing exactly why a URL was flagged using SHAP feature attributions and top predictor rankings.

### 5. ⚡ Batch URL Scanner (`/batch`)
High-throughput tool to upload, analyze, and monitor multiple URLs simultaneously with queue status and data export options.

### 6. 🔒 Web Security & Trust Audit (`/security-audit`)
Comprehensive audit page evaluating a domain's SSL/TLS certificate health, HTTP security headers, and combined Digital Trust Score.

### 7. ⚠️ Threat Alerts Center (`/alerts`)
Early warning monitoring hub displaying 4-stage threat level alerts, suspicious domain patterns, and community intelligence feeds.

### 8. 📊 Model Performance & Metrics (`/model-metrics`)
Scientific evaluation dashboard showcasing XGBoost vs Random Forest benchmark results, confusion matrix, and ROC/PR curves.

### 9. ⚙️ Settings & API Hub (`/settings`)
Administrative panel for adjusting classification thresholds, managing API keys, configuring alert webhooks, and accessing API documentation.
